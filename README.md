# Aurora Grand Hotel Website

A responsive hotel website demo built with HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — responsive styling
- `script.js` — mobile menu and booking enquiry form

## Run
Open `index.html` in a browser. An internet connection is needed for the online photos and Google Fonts.

## Customize before publishing
Replace the demo hotel name, phone number, email, address, room prices and photos with your real hotel details.

## Note
The booking form is a front-end demo only. It does not check live room availability, store bookings, or process payments. A backend and booking service are needed for real reservations.
